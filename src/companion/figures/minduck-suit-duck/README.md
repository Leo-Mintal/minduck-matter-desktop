# 西装鸭

Coopanion manifest 2 / API 2，ID：minduck-suit-duck。
形象包版本 1.3.0。待机、工作、询问、成功、失败使用 2026-11-23 的五份独立原稿，其他动作沿用 2026-11-20 的合集。

| --- | --- | --- |
| 01 原地走路与待机过渡 | gait 走路/跑步 | 连续迈步片段循环 |
| 02 待机 | neutral 待机 | 原始完整 8 秒循环，含呼吸与眨眼 |
| 03 电脑工作 | work 工作 | 完整 8 秒，1.35 秒进入、4.5 秒开始收回 |

Matter 已有任务映射继续使用 work / ask / happy / sad；其他新增动作可通过形象词表调用。
默认 `do(word)` 仍按上表有限时长播放。Matter 自动工作和确认通过 `do(word, { repeat: true })` 只循环进入后的持续段；任务状态改变时经 `finishFlow()` 收尾，再切到下一动作。仅 `work` / `ask` 支持该持续模式，手动动作和成功/失败不循环。
播放时每帧只显示一套不透明身体，不增加整只淡入淡出；原画内部的透明度关键帧保持不变，隐藏的基础身体不重复绘制。完整动画和爱心、眨眼等基础表情都通过独立 `animating` 标志请求宿主配置的动画帧率，避免基础表情回落到 30 FPS；不冒充物理移动，也不妨碍点击/随机思考。
运行时保留可选的形象自有思考视图与额外可恢复动作声明，其他形象沿用原逻辑。所有动画仅由宿主 `step(dt)` 推进。
动作取消按源素材收回道具；拖拽、投掷与落地恢复保留工作类动作。走路/跑步循环连续步态片段，其余跳跃、招手、扑翅膀、说话仍由宿主驱动。

原文件和各动作的 SHA-256 保存在桌面仓库的 `assets/companion-suit-duck/`。五种业务状态提取自各自原稿的角色组，保留原动画和道具，去除展示卡片的底色与标签。
使用 `python3 scripts/build-suit-duck.py` 重新生成画稿；`--check` 验证产物与源文件一致。
转换器只使用 Python 标准库，支持本批素材的 transform / opacity / offset-distance 与原静态 motion-path 样式；未知属性明确报错。
`project.json` 的画布对齐来自原图脚掌边界测量；各动作按脚掌尺寸统一角色比例和地线，不按动画画布宽度缩放角色。
原始路径、颜色、滤镜原语与图层顺序保留；不联网加载素材。
部分原 SVG 的滤镜边界为非法 `inf/-inf`，生成时按实际图形范围加模糊余量修正，原始文件保持不变。
新版画稿中同色的袖子填充和描边在生成时连续覆盖底层，消除原本可见的黄色细线。询问和抱资料的单白色轮廓遮罩继续转为相同路径的裁剪。原稿和动画轨道保留。

用户提供的西装原画未被赋予公开许可；官方运行时许可见LICENSE-Coopanion.txt。
