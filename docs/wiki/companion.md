## Status-to-action mapping (enabled)

Verified contract: backend `services/api/internal/app/matter/models.go` defines Turn statuses `running`, `waiting`, `done`, `failed`, `stopped`; Run adds `pending`. Idle is derived locally, not a backend status. The default ordinary duck and optional Police/Suit Duck packs declare `work`, `ask`, `happy`, but no dedicated failure, cancellation or queue animation.

| Backend status | Automatic action | Notes |
| --- | --- | --- |
| `pending` (Run only) | `ask` (询问) | User-specified presentation; pending remains a Run-only backend status. |
| `running` | `work` | Thinking, search, tools and writing all use work; details remain in the capsule. |
| `waiting` | `ask` | Answer, approval, attachments and external authorization share ask, with distinct text. |
| `done` | `happy`, once, then idle | Existing expression, not a dedicated completion flow. |
| `failed` | error → `sad`, once, then idle | Reuses the kit's existing expression; no new artwork. |
| `stopped` | error → `sad`, once, then idle | User-specified error presentation, same as failed. |
| No active tasks | idle | Allow configured roaming. Network loss/logout are not completion/failure events. |

Arbitration: any running task → work; otherwise any pending/waiting task → ask. While tasks remain active, terminal results never interrupt them. Remember observed results for that concurrent batch; when all settle, any failed/stopped result wins over success. Only active → terminal transitions observed in the read-only list create cues; historical results, deleted rows, logout, network loss and organization switches do not create a result. Cues have bounded IDs and a ten-second delivery lifetime, survive the normalized native bridge and play once per sandbox. Work/ask repeat their original finite flows; transitions wait until the full current flow or actual expression ends (happy/sad use the kit's actual 3.2 seconds, not manifest guesses). Dragging preserves the latest desired state, including task completion while carried. Original packs, figure selection, panel styles, shared Web/backend and client chrome remain unchanged.
