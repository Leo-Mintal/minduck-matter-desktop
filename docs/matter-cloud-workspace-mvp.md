# Matter 接入云电脑的讨论记录

我们希望把 Matter 做成面向 OPC 和办公人群的“工作搭子”。目前浏览器和 Shell 等操作主要在用户本机执行，用户关机、不方便使用电脑时，就缺少一台能继续替用户工作的云电脑。

## 最新想法

- **提供一台“Matter 的电脑”**：把云电脑当作用户的第二台独立电脑，有完整桌面、浏览器、Shell 和文件处理能力，不再考虑 WebVM。
- **保留本机，增加选择**：用户可以选择让 Matter 使用“本机”还是“Matter 的电脑”。这会取代前面“所有浏览器操作统一迁到云端”的想法，本机和云电脑两种方式都保留。
- **用积分租电脑**：例如扣 1000 积分使用一天。这里只是举例，具体价格、租期和续费方式还没定。
- **租好后自动接入 Matter**：云电脑绑定到用户账号，作为一台独立执行设备接收任务，拥有自己的设备身份，不覆盖原本的本机配对。
- **可以看到完整桌面**：入口处可以用鸭子写代码等动画表示工作状态；点进去能看到完整系统桌面，了解 Matter 正在浏览网页、使用终端还是处理文件。通过 Shell 在后台运行的命令也需要有可查看的执行记录。
- **可以聊天控制，也可以自己接管**：用户通过聊天安排云电脑工作；需要输入密钥、支付等操作时，可以自己接手，处理好后再交回 Matter。人工接管期间，AI 暂停操作，避免双方同时控制。
- **本机关机后，云电脑仍可工作**：已经交给云电脑的任务不依赖用户电脑运行，结果保存在云端。用户可以通过其他可用设备访问 Matter 继续安排工作。

比如用户出门前把调研任务交给 Matter 的电脑，云端就继续查网页、下载资料、处理文件、整理报告，用户自己的电脑可以关掉。

## 还需要讨论的问题

- **任务做到一半怎么换电脑？** 本机执行一半后关机，云端是否接着做？文件、网站登录态、软件环境和执行进度都可能不同，不能默认无缝接上。建议第一版先让任务固定在选定的电脑上，跨电脑继续作为后续能力。
- **由用户选，还是自动选？** 建议第一版由用户明确选择；本机离线时提示当前设备不可用，让用户决定是否改用已租的云电脑。后续再考虑用户预先开启“自动使用云电脑”的选项。
- **浏览器和 Shell 怎么对应？** 选择一台电脑后，这个任务的浏览器、Shell 和文件操作都应该使用那台电脑，避免浏览器在云端、文件却落在用户本机。
- **租期结束怎么处理？** 需要确定到期任务怎么办、是否自动续费、文件和登录态保留多久，以及用户是否可以重新租回原来的环境。
- **用户接管时怎么交接？** 需要明确 AI 暂停、用户操作、交还控制的状态；登录或验证码等需要人参与时，应当等待用户。

## 现有 Shell 能力能不能复用

方向上可以沿用“设备配对 → 设备主动连接 Matter → 接收工具调用 → 返回结果”的方式。对云电脑里的执行端来说，Shell 执行的也是它自己那台电脑上的命令。

但不能只配对就直接用：当前桌面执行端依赖 macOS 权限、系统沙盒、Electron 和主窗口登录状态。Linux 或 Windows 云电脑需要适配执行端，并让它在用户退出客户端后独立运行。

目前 Shell 还是短时命令模式，单条最长两分钟，没有交互终端和后台常驻任务管理；完整桌面显示、键鼠接管、可见终端，以及跨设备任务选择都需要另外补。浏览器设备和 Shell 设备当前也分别配对，需要将它们对应到同一台“Matter 的电脑”。

还要核对服务端任务是否能脱离聊天页面持续运行；设备在线本身不代表任务一定能在客户端断开后继续。以上是客户端及 Web 代码的核对结果，尚未做云电脑实际接入验证。

## 接下来要调研的事

- 看哪些云电脑厂商性价比合适，比较同配置的算力、桌面连接、带宽、存储及停机后的费用。
- 确认能不能通过接口自动创建、启动、停止云电脑，能否把桌面嵌进 Matter，是否允许安装我们的执行端并提供给用户租用。
- 对比现成云桌面和租云服务器自己搭桌面两种方式，先选一个小规格做实际验证。
- 用同一个小任务验证：租用和配对 → 选择 Matter 的电脑 → 浏览器下载资料 → Shell 处理 → 查看桌面和人工接管 → 关闭本机后继续执行。

2026-11-11 先查看了两家的官方资料，可以作为调研起点：

- [阿里云无影云电脑企业版](https://www.aliyun.com/product/edse)：提供按月和按需购买方式，官方文档有云电脑管控 API 和客户端 SDK，后续重点确认桌面嵌入和对外租用的条件。
- [华为云 Workspace](https://www.huaweicloud.com/product/workspace.html)：提供云桌面和办公时长套餐，并开放 API，后续重点确认客户端集成方式及实际套餐费用。

现在还不能判断哪家最便宜。月套餐里的使用小时数、超时费用、带宽、磁盘和无人连接时是否继续运行都要一起比较，官网促销价不能直接当成长期租用成本。

## 后续可以扩展的功能

下面先记一些可以做的方向，后续再按需要接入对应工具和服务。

- **定时任务**：每天早上搜集行业新闻、每周整理竞品动态，到点自动执行，用户不用开电脑。
- **持续调研和变化提醒**：定期查看指定网站，发现价格变化、新产品、招标信息等，整理后提醒用户。
- **OCR 文字识别**：把截图、扫描件、票据里的文字和表格提取出来，整理成文档或表格。
- **PDF 和文档处理**：批量阅读、总结、翻译、合并或拆分资料，从多份文件中提取需要的信息。
- **表格和数据处理**：清洗数据、去重、合并表格、计算指标，生成图表和分析报告。
- **音视频处理**：视频转音频、录音转文字、生成字幕和会议纪要，也可以做格式转换和压缩。
- **批量文件整理**：自动分类、重命名、解压和打包文件，按照项目或日期整理资料。
- **自动生成报告**：把网页调研、文件分析和数据结果串起来，定期生成日报、周报或专题报告。
- **固定工作流程**：把经常重复的步骤保存下来，比如“下载报表 → 整理数据 → 生成报告”，之后一句话或按时间执行。
- **业务网站协同**：在用户授权后，从不同业务网站收集信息，整理后填写到另一个系统，减少重复操作。
- **手机安排工作和接收通知**：人在外面也能发起任务、查看进度，完成后收到通知，需要时接手处理登录等操作。
- **团队共享成果**：把云端生成的报告、文件和任务记录分享给同事，方便继续协作。

可以优先考虑定时任务、网站变化提醒、OCR 和文档／表格处理，比较贴近调研和日常办公场景。
